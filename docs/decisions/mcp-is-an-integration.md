# MCP is an integration, not an in-app chat

`pacs-mcp` lets a hospital's own AI assistant query priors, with sources and an audit line. The demo shows this on a separate integration page. Inside the app, MCP tools appear only as the visible tool calls of a dispute re-judge.

## Options

- A case-level chat with preset questions: rejected. Its answers repeat what the case screen already shows, so it reads as a gimmick.
