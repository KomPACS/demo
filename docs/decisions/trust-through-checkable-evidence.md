# Trust comes from checkable evidence, not a confidence number

A coordinator trusts a verdict when the source can be checked in seconds. A link proves a sentence exists, not that the AI read it right (a planned exam can be read as done). So each verdict shows the sentence with its real neighbours, the event status and the word that decided it, the number of independent sources, and numbered steps tagged **Systém** (a repeatable lookup, with the time it read the data) or **AI** (the model's reading).

## Options

- A confidence percentage: rejected. A model's self-reported confidence is not calibrated, and a doctor reads "92 %" as a measured value.
- Free-text reasoning only: rejected. It reads as a voice asking to be believed and cannot be checked.

## Consequences

- Context sentences must be verbatim neighbours in the cited report. A seed test enforces it.
- A planned or recommended exam is never a relevant prior.
